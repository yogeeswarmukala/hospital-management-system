# Hospital Management System

## Project Overview

The Hospital Management System is a database project developed using MySQL to organise and manage hospital-related information.

This project focuses on relational database design, table creation, data management and SQL query implementation.

## Technologies Used
- MySQL
- SQL
- MySQL Command Line Client

## Database Tables

### 1. Department
Stores department names, locations and contact information.

### 2. Doctor
Stores doctor details, specializations, email addresses, phone numbers and salary information.

### 3. Room
Stores room numbers, room types, daily charges and availability status.

## SQL Concepts Implemented
- Database creation and management
- Primary Key and Foreign Key
- Unique Constraints
- AUTO_INCREMENT
- WHERE and ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- LIKE, BETWEEN and IN
- INNER JOIN and LEFT JOIN
- Table constraints
